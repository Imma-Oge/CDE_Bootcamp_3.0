# CDE Bootcamp 3.0: My Data Engineering Journey

## About This Repository

This repository is a central record of my journey through CDE Bootcamp 3.0, a hands on data engineering training program. It brings together all the modules, assignments, and projects completed during the program in one place, so the full progression from fundamentals to advanced tooling is easy to follow.

Individual assignments are also submitted in their own dedicated repositories as required by the program. This repository exists to document the journey as a whole and serve as a portfolio of the work done.

## About the Bootcamp

CDE Bootcamp 3.0 covers the full data engineering lifecycle, including:

* Linux and Git fundamentals
* SQL
* Python for data engineering
* Data modelling
* Docker
* Terraform
* Kubernetes
* dbt
* Airbyte
* Spark
* Airflow
* Cloud platforms

## Repository Structure

Each folder in this repository represents a completed module or project, with its own dedicated README covering the objective, approach, and outcome.

```
CDE_Bootcamp_3.0/

```

New folders are added as the program progresses.

## Case Study Context

A number of the projects are built around a case study involving Beejan Technologies, a telecommunications company that receives thousands of customer complaints daily through channels such as Twitter (X), SMS, website forms, and call center logs. The assignments use this scenario to practice designing and building end to end data engineering solutions, from ingestion through to reporting.
